# 可视化基金池

面向普通投资者与一线理财师的基金优选工具。打开页面即可看到某个方向上按风险收益效率排序好的完整榜单，再按基金公司、类型、关键词二次筛选。

数据源为东方财富公开接口采集的全市场基金快照，业绩与回撤全部本地按复权净值重算，并用 Wind 抽样对账。

---

## 一、池子结构

共 12 个池，分两个方向。

**主动方向（5 个）**

| 池 | 筛选范围（投资类型二级分类） |
|---|---|
| 主动权益池 | 普通股票型、指数增强型、偏股混合型、灵活配置型、可转债、股票型 FOF、混合型 FOF |
| 中波固收池 | 平衡混合、偏债混合、灵活配置、混债一级、混债二级、债券 FOF、可转债 |
| 低波固收池 | 混债一级、中长期纯债、短期纯债、债券 FOF |
| 海外池 | 国际(QDII)股票型、国际(QDII)混合型、国际(QDII)债券型、国际(QDII)另类 |
| 商品池 | 黄金、白银、豆粕、大豆、原油、石油、天然气、有色金属期货、能源化工、商品期货、大宗商品、抗通胀等商品类基金 |

**被动方向（7 个）**：股票宽基、股票行业、股票策略、债券、QDII 股票、QDII 债券、QDII 商品。按指数标的做细分分类，映射表在 `server/src/config/indexTaxonomy.js`。

同一只基金的 A/C/E 份额合并为一个条目，只保留初始份额，避免同一产品重复占位。

## 二、筛选管线

严格按顺序执行，每一层的结果都可在页面上展开查看：

1. **可买入** —— 剔除申购状态为「暂停申购」「暂停大额申购」「限大额」「限购」「封闭」「终止」的产品。「场内交易」按可买入处理，ETF 的买入走交易所撮合，不依赖申购通道。
2. **基金经理任职满 3 年** —— 现任经理中只要有一位在本基金任职满 3 年即通过。
3. **剔除近 3 年最大回撤排名池内后 50%**
4. **剔除近 3 年年化收益排名池内后 50%**
5. **按卡玛比率降序**

「同类」的口径是**池内排名**，不按 Wind 二级分类分组。卡玛比率 = 几何年化收益 ÷ |最大回撤|。

池内样本口径：初始份额 + 成立满 5 年 + 最新规模 ≥ 2 亿元。这三个参数集中在 `server/src/config/caliber.js`，改这一处即可，采集脚本、导入器、筛选引擎和前端文案会同步跟随。

## 三、数据口径

这一节是项目的核心，几个坑都踩过。

### 复权净值，不是累计净值

东财 `Data_ACWorthTrend` 给的是累计净值：分红只加回本金、不做再投资。拿它算收益，高分红基金会被严重低估——易方达科讯近三年用累计净值算出 86.7%，Wind 复权口径是 177.4%，差一倍。

正确做法是用 `Data_netWorthTrend` 每个点的 `equityReturn`（已含分红的当日增长率）逐日累乘重建复权净值。修正后同一只基金算出 177.25%。

区间收益的基准要取「窗口起点日或之前最后一个净值」，否则会漏掉起点到首个披露日之间的涨跌。

### 基金经理任期要串接

经理任职起始日取自东财 F10 经理变动页 `https://fundf10.eastmoney.com/jjjl_{code}.html`，该页面服务端直出，表头为「起始期 / 截止期 / 基金经理 / 任职期间」。

坑在于：东财在增聘共同经理时会把同一位经理的连续任期拆成两行。中欧医疗健康的葛兰 2016-09-29 就接手，2025-07-04 增聘赵磊后记录被拆成两段，只取「至今」那行会把管了 9 年的经理误判成 1 年。解析时需沿「同姓名 + 上一行截止期紧接下一行起始期」向前串接。

### 对账结果

对 3 只基金用 Wind `get_fund_performance` 的区间复权净值增长率与区间最大回撤做核对：回撤误差 ≤ 0.03 个百分点，区间收益相对误差 < 2%（残差来自日增长率保留两位小数后的累乘累积）。

### 爬取注意事项

- `fundmobapi.eastmoney.com` 只认短 UA（`Mozilla/5.0`），完整 Chrome UA 会返回 `ErrCode 61136403`；`fund.eastmoney.com/pingzhongdata` 走网页通道，需要完整 UA。两个 UA 必须分开。
- 不要用裸 `requests.get` 跑几千次：Windows 动态端口 16384 个、TIME_WAIT 240 秒，跑一两千次就会耗尽并报 `WinError 10048`，表现像对端限流。用线程内常驻 `Session` 加连接池复用。
- `deviceid` 与 `plat` 都传 `Wap`。

## 四、快速开始

环境要求：Node.js ≥ 22.5（用到内置 `node:sqlite`），Python 3.10+（仅重新采集数据时需要）。

```bash
# 安装依赖
npm run install:all

# 从快照导入数据库（仓库已带 server/data/snapshot/em-full.json）
npm run import

# 构建前端
npm run build

# 启动服务（默认 http://127.0.0.1:8787）
npm run server
```

开发模式下前后端分开跑：

```bash
npm run server   # 后端 :8787
npm run web      # 前端 :5173，vite 代理到后端
```

### 重新采集数据

仓库里的快照是 2026-10-27 的。要更新到最新：

```bash
cd server/scripts
pip install requests akshare

python sync_eastmoney.py      # 全市场基金基础数据 + 复权净值，约 20 分钟
python sync_manager.py --all  # 基金经理任职起始日，约 40 分钟
python recalc_nav.py          # 全量重算收益与回撤（增量修正时用）
```

`fill_nav.py` 只补 `mdd3y` 为空的记录，可反复跑。

## 六、已知限制

- **QDII 类池子数量极少甚至为空。** 跨境产品的申购状态受外汇额度约束，绝大多数长期处于「限大额」或「暂停申购」。严格口径下 QDII 债券池会归零。这是数据事实，页面空态里写明了原因。
- **卡玛排序偏袒低波动产品。** 权益池头部会混进弹性很低的灵活配置型基金，看着像债基。要纯权益弹性，得另加仓位或波动门槛。
- **数据为日频快照，不含盘中估值。** 申购状态变化频繁的产品（尤其 QDII）实际可买性以购买当日为准。
- 目前只有 PC 布局，移动端适配未做。
